just-did

Overview

Just Did (刚刚做了什么) is a mobile app designed to help you record daily activities locally. We are committed to protecting your privacy. This Privacy Policy explains how we handle your data.

Data Collection and Processing

We do NOT collect, transmit, or store your personal data on our servers.

All data processing is done entirely on your device:

  • Staging Records: Daily activity records are stored locally on your phone in text files (format: staging-YYYYMMDD.txt)
  • Daily Reports: Documents fetched from your desktop app are stored locally on your phone
  • App Configuration: Connection settings and app preferences are stored locally using Android DataStore
  • Database Indexes: Daily report metadata (dates, file paths, sizes, sync status) are stored in local Room database

Network Communication

This app communicates only with your personal desktop app (Just Did Desktop) over your local network:

  • Health Check: Periodic connectivity verification (every 60 seconds) — read-only, no side effects
  • Data Sync: Uploading staging records to your desktop app
  • Data Fetch: Downloading daily reports from your desktop app

Communication Details

  • Protocol: HTTP (local network only, not transmitted over the internet)
  • Endpoints:
    • GET /health — Connectivity check
    • POST /sync/submit — Upload staging records with batch ID (idempotent)
    • POST /sync/fetch — Download daily report content
    • POST /sync/fetch-index — Download report metadata

All network communication is local to your LAN and never leaves your home network. The app has no internet access capability.

Data Storage

All data remains on your device:

{App Private Directory}/
  staging/                      # Daily activity records
    staging-YYYYMMDD.txt
  data/                         # Fetched daily reports
    YYYY/MM/DD.txt
  Room Database                 # Report indexes
  DataStore                     # Configuration
  • No Cloud Upload: Data is never uploaded to the cloud or any remote server
  • No Backup to Cloud: This app does not participate in automatic cloud backups
  • Local Only: All data is exclusively stored on your phone and desktop computer

Data Deletion

You have full control over your data:

  • Manual Deletion: Use the app's management page to delete staging records or daily reports
  • App Uninstall: Uninstalling the app will remove all app data and local storage
  • No Remote Data: Since no data is stored remotely, no additional deletion actions are needed

Third-Party Services

This app does NOT use:

  • Analytics services (Google Analytics, Mixpanel, etc.)
  • Crash reporting services (Firebase Crashlytics, Sentry, etc.)
  • Advertising networks (AdMob, etc.)
  • Social media SDKs
  • Cloud storage services (Google Drive, Dropbox, etc.)

Permissions

This app requests the following Android permissions:

Permission Purpose Why Needed
INTERNET Local network communication To sync with your desktop app over LAN
READ_EXTERNAL_STORAGE File access To read/write activity records (Android 11 and below)
WRITE_EXTERNAL_STORAGE File access To store staging records and reports (Android 11 and below)
CAMERA QR code scanning To scan desktop app's connection QR code

Security

  • Local Processing: All data processing happens on your device only
  • No Encryption: Since data never leaves your device, it's protected by your phone's device encryption
  • Open Source: The source code is available on GitHub for security review
  • No Backdoors: No telemetry, tracking, or hidden data collection

概述

刚刚做了什么（Just Did） 是一款帮助你本地记录日常活动的手机应用。我们致力于保护你的隐私。本隐私权政策说明我们如何处理你的数据。

数据收集与处理

我们不收集、传输或存储任何个人数据到服务器。

所有数据处理都仅在你的设备上进行：

  • 暂存记录：每日活动记录作为文本文件存储在你的手机本地（格式：staging-YYYYMMDD.txt）
  • 日报内容：从电脑端应用拉取的文档存储在你的手机本地
  • 应用配置：连接设置和应用偏好设置使用 Android DataStore 存储在本地
  • 数据库索引：日报元数据（日期、文件路径、大小、同步状态）存储在本地 Room 数据库

网络通信

此应用仅与你的个人电脑端应用（刚刚做了什么桌面版）通过本地局域网通信：

  • 健康检查：周期性连接验证（每 60 秒一次）——只读，无副作用
  • 数据同步：将暂存记录上传到电脑端应用
  • 数据拉取：从电脑端应用下载日报内容

通信详情

  • 协议：HTTP（仅限局域网，不通过互联网传输）
  • 端点：
    • GET /health — 连接检查
    • POST /sync/submit — 上传暂存记录（批次 ID 幂等）
    • POST /sync/fetch — 下载日报内容
    • POST /sync/fetch-index — 下载报告元数据

所有网络通信都在你的局域网内进行，永远不会离开你的家庭网络。应用不具备互联网访问能力。

数据存储

所有数据都保存在你的设备上：

{应用私有目录}/
  staging/                      # 每日活动记录
    staging-YYYYMMDD.txt
  data/                         # 拉取的日报
    YYYY/MM/DD.txt
  Room 数据库                    # 日报索引
  DataStore                     # 配置
  • 不上传到云端：数据永不上传到云或任何远程服务器
  • 不备份到云：此应用不参与自动云备份
  • 仅限本地：所有数据仅存储在你的手机和电脑上

数据删除

你对数据拥有完全控制权：

  • 手动删除：使用应用管理页面删除暂存记录或日报
  • 卸载应用：卸载应用将删除所有应用数据和本地存储
  • 无远程数据：由于数据不存储在远程，不需要其他删除操作

第三方服务

此应用不使用：

  • 分析服务（Google Analytics、Mixpanel 等）
  • 崩溃报告服务（Firebase Crashlytics、Sentry 等）
  • 广告网络（AdMob 等）
  • 社交媒体 SDK
  • 云存储服务（Google Drive、Dropbox 等）
